# Fuentes tipográficas incluidas

Estas fuentes se incluyen para poder **editar texto en PDF de Gamma** (las fuentes embebidas en esos PDF son subconjuntos de
glifos y no permiten escribir texto nuevo). Todas son de código abierto bajo la **SIL Open Font License 1.1 (OFL)**. Se
tomaron del repositorio oficial https://github.com/google/fonts; el texto de licencia y el aviso de copyright de cada familia
está en el archivo `OFL-<familia>.txt` de esta carpeta, copiado tal cual del repositorio.

| Familia | Archivos | Licencia / aviso |
|---|---|---|
| Open Sans | OpenSans-Regular.ttf, OpenSans-Bold.ttf | OFL-opensans.txt |
| PT Sans | PTSans-Regular.ttf, PTSans-Bold.ttf | OFL-ptsans.txt |
| Nunito | Nunito-SemiBold.ttf | OFL-nunito.txt |
| Heebo | Heebo-Regular.ttf, Heebo-Bold.ttf | OFL-heebo.txt |
| Instrument Sans | InstrumentSans-Medium.ttf, InstrumentSans-SemiBold.ttf | OFL-instrumentsans.txt |
| Corben | Corben-Regular.ttf | OFL-corben.txt |
| Crimson Pro | CrimsonPro-SemiBold.ttf | OFL-crimsonpro.txt |
| Libre Baskerville | LibreBaskerville-Regular.ttf | OFL-librebaskerville.txt |
| Nobile | Nobile-Regular.ttf, Nobile-Bold.ttf | OFL-nobile.txt |
| Inter | Inter-Regular.ttf | OFL-inter.txt |
| Manrope | Manrope-Regular.ttf, Manrope-Bold.ttf | OFL-manrope.txt |

La licencia OFL permite usar, estudiar, copiar, modificar y redistribuir las fuentes, siempre que se conserve el aviso de
copyright y la licencia y que las fuentes no se vendan por sí solas. Estos archivos conservan ambos. Si una presentación usa una
familia que no está acá, descargala del repositorio de Google Fonts (avisando al tutor) y agregala a esta carpeta con su OFL.
